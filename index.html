LEARNING GUIDE · A–Z SYSTEM

Learn the rules, not just phrases.

This guide is based on the uploaded Channa Zorin Spoken Language Guide. Examples and spellings are kept in the guide's form.

A · Sentence order

Subject + Time / Place / Modifier + Object + Verb
Channa Zorin uses SOV order.

Unio bonnokath kalea
මම බත් කනවා · I eat rice.

Simio gonnokedara yalea
ඔයා ගෙදර යනවා · You go home.

B · Pronouns

C · Name endings only

These suffixes are for personal names and place names only, not common nouns.

-ට -n
-ගේ -k
-ව -m
-ගෙන් -dea
-ම -l

Channan · Channak · Channam · Channadea · Channal

D–G · Prefix + first-letter swap

Common nouns: konno + word → swap first letters
poth → ponnokoth
Adjectives: pipo + word → swap first letters
hoda → hipopoda
Question words: sea + word → swap first letters
koheda → keasoheda
Connectors: line + word → swap first letters
nisa → ninelisa

H · Time and place words

දැන් · dan ditan
ඊයේ · iye yitaye
හෙට · heta hiteta
මෙතන · methana mipetha
එතන · ethana eipetha
ඉක්මනින් · ikmanin ipikman

I · Number system

A–I sequence with place endings: units -rio, tens -ko, hundreds -pin, thousands -mba, hundred-thousands -mo.

Examples: 14 = Ako Drio · 25 = Bako Erio · 342 = Tapin Dako Brio.

J · Spoken verb system

Present · root + lea kalea
Continuous · -zi kaleazi
Having done · -zu kaleazu
Infinitive / command · va kaleava
Past · -ta kaleata
Future · -ra kaleara
Let's · -aza kaleaza
Question · da kaleada
Negative · ma kalema
